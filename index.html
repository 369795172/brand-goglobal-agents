获客内容的瓶颈不是生成，是持续供给平台原生形态内容的工程纪律。
一次输入，五种原生形态同一选题，X 是短断言串，Reddit 是长上下文帖，小红书是第一人称体。差异不是翻译，是按平台规范重写。
声纹在提示词层硬约束句法节奏、立场分档、禁用词表写进系统提示，违规稿由编辑环节打回，而不是靠人肉把关。
发布门前置每份交付包自带人工确认清单：标题、社区规范、来源锚点、时机、声纹自检五项，全过才允许发布。

系统架构：六层管道research → topic → production → state → publish → evidence

demo 是核心环的最小化。生产系统从研究语料到证据回流是一条完整管道，本页演示的是「生产层」的关键机制。
研究层

选题层
63 选题入册 / 11 个方向；优先级评分模型（160-250 分）
生产层
五段式多 Agent 文案流水线 + 声纹约束（本页 demo）
状态层
本地 SSOT → 飞书五表幂等同步（398 行，重跑 create=0）+ 终态保护
发布层
渠道 Adapter + 发布门；人工确认后才出站
回流层
发布包 · 证据链 · SHA-256 清单，数据回流选题层
↺ 发布数据回流选题层，形成闭环：同一套语料、评分与声纹资产被每一条内容复用
