# 02 · Agent 技术方案

评审维度：Agent 技术方案（25%）。

## 设计原则

三条，从运行经验里长出来的，不是设计出来的：

1. **人守判断点，Agent 守产能。** 选题取舍、声纹审核、发布确认是人机协作的三个硬门，其余环节全部管道化。
2. **单一事实源。** 所有状态（选题、排期、发布）只有一个 canonical 存储，其他视图（飞书看板、日历）全是投影。投影可丢，SSOT 不可丢。
3. **每一步可审计。** 幂等同步、终态保护、SHA-256 证据清单。内容生产当工程系统做，不当灵感做。

## 六层架构

### 1. 研究层：竞品与受众语料

- 66 个竞品账号、198 条内容样本，覆盖 7 个平台（bilibili / xiaohongshu / weibo / wechat_oa / channels / x / youtube）。
- 每条样本记录形态、数据、URL；90 条真实 URL，人工抽检 20 条通过 16 条（80%）。
- 数据质量诚实披露：粉丝数缺失率 72.7%、播放数缺失率 69.7%。宁可缺失，不编造。

### 2. 选题层：数据驱动的 backlog

- 63 个选题入册，分 11 个方向；每个方向有需求证据分（19.17 到 10.0）。
- 优先级评分模型综合需求强度、供给稀缺度、产能成本，Top12 队列按分排序进入生产。
- 选题不是灵感，是队列。数据回流（第 6 层）直接改写下一轮排序。

### 3. 生产层：五段式多 Agent 文案流水线

```
策略洞察 → 文案起草 → 编辑审核 → 渠道适配 → 终校
```

- **策略洞察**：输入受众分层与方向证据，输出本次内容的切入角度与成功标准。
- **文案起草**：按品牌声纹约束生成初稿。
- **编辑审核**：独立 Agent 审核稿，对照声纹清单与禁用词表打回不合格段落。
- **渠道适配**：核心稿件拆解为各平台原生形态（B 站口播稿、公众号长文、小红书第一人称体、微博短断言串、X 英文短帖、Reddit 长上下文帖）。
- **终校**：数字核对、来源锚点、置信度标注，产出可发布交付包。

**声纹约束是本层的差异化设计**：一份 L1-L7 分层的品牌声纹档案（句法节奏、立场强度、类域偏好、禁用词表、生成后自检清单）作为系统提示注入每个写作 Agent。解决的是 AI 内容最致命的问题：AI 味。管道越自动，声纹越关键。

### 4. 状态层：本地 SSOT + 飞书五表投影

- 本地 jsonl/yaml 是 SSOT：受众（5）、账号（66）、样本（198）、选题（63）、发布（100 行实际）。
- 同步 CLI 幂等 upsert 到飞书五表：无 unique_key 拒绝写入；重跑 create=0 实测通过。
- 终态保护：飞书手工标记「已发布 / 已搁置」的行，同步不覆盖其受保护字段。人工判断优先于机器覆盖。
- EDL 审阅文档链路：剪辑决策表（YAML）发布为飞书审阅文档，人工在飞书批注，SSOT 仍在本地。

### 5. 发布层：渠道 Adapter + 发布门

- 每个平台一个 adapter：格式规范、发布节奏、平台规则、文化适配（英文平台的表达习惯与中文平台分开约束）。
- **发布门（publish gate）是硬性人工确认点**：清单式检查（封面、标题、标签、平台规范、时机），任一项 pending 不发布。已落地案例：一条竞赛内容通过 10 项发布门检查后才进入待发队列。

### 6. 回流层：发布包与证据链

- 每条内容归档完整发布包：脚本、素材索引、成片、发布渠道、时间。
- 关键证据 SHA-256 哈希入清单，保证「我做过、做到了什么程度」可验证。已落地案例：一次 AI 设计到实物的完整链路（48.5 公里实地验证、137 层切片、21.69 克耗材、135,254 次挤出动作，全部哈希存证）。

## 海外扩展设计（本赛题的核心增量）

国内 pilot 已验证的管线，向赛题指定的海外平台扩展：

| 平台 | Adapter 要点 | 阶段 |
|---|---|---|
| X | 一条一判断、数据 hook、来源标注；英文短断言体 | 第一批 |
| Reddit | 长上下文、真实数据、反营销腔；subreddit 规则适配 | 第一批 |
| INS | 视觉模板 + 短文案；标签策略 | 第二批 |
| Discord | 社区公告与频道口吻；节奏克制 | 第二批 |

扩展的本质是加 adapter 配置，不动管道本体。这是「已验证系统的海外扩展」，不是从零开始的新项目。

## 任务流程示例（一次完整生产）

```
选题 T-D11-01 入队（优先级评分）
→ 策略 Agent 输出切入角度与成功标准
→ 文案 Agent 产出多渠道稿（声纹约束）
→ 编辑 Agent 打回两段不合格表达 → 修订
→ 素材管线：37 个文件入库、索引、4 级判定
→ 剪辑管线：粗剪 v1 → v3（81.3 秒定稿）
→ EDL 审阅文档发布到飞书 → 人工批注
→ 发布门 10 项检查 → B 站待发队列
→ 发布包归档 + 证据哈希
```

全程一人守门，Agent 完成其余。
