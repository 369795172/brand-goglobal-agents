# 04 · 业务价值与实际效益

评审维度：业务价值与实际效益（25%）。

## 口径声明（先说清规则）

系统 2026-09 起进入生产爬坡期，新品牌已发布内容 1 条，互动数据暂无回流。因此本文全部数字按**产能、人效、工程可靠性**三个口径陈述，不用增长口径。每个数字可回溯到生产系统的记录。我们认为评委对诚实口径的信任，价值高于包装出来的增长曲线。

## 二、人效（一人 + Agent 的真实成本）

- 单集全流程人时：**3-5.5 小时**（Top12 队列 12 集估时合计约 47.5 小时，含拍摄）。
- 一次产出是多渠道交付包：B 站口播稿 + 公众号长文 + 小红书图文 + 2-3 条微博短帖 + 社区帖。
- 对照口径：行业常识里一条像样的多平台品牌内容（选题 + 撰写 + 适配 + 排期）人工全流程普遍在 8 小时以上。我们的 3-5.5 小时含实拍；纯图文选题不含拍摄可压到 2 小时内。
- 摄影技能进步可量化（刻意练习体系）：第一轮练习稳定性评分 0.6/2（最低项），第二轮同维度信号向好；远景覆盖从 0 到有；全天音轨覆盖从 0 到 80 条。单人能力在管线里被系统化拉升。

## 四、市场对照（明确标注：市场分析数据，非本团队业绩）

研究语料中的竞品数据，说明赛道需求规模：

- B 站：Harness 教学类单条 135.9 万播放；头部账号 100.9 万粉丝。
- YouTube：Karpathy 深度解析 908 万播放；Claude Code 课程类 236.7 万播放。

需求被验证，供给稀缺（多数同类账号 20 条内断更）。我们用工程纪律换持续供给能力，这是系统的业务价值主张。

## 五、价值模型（对客户/品牌的可迁移性）

换一个品牌 = 换一份配置：受众分层 + 声纹档案 + 渠道组合 + 选题方向库。管道本体零改动。

对出海品牌的量化预期（推断，非实测，置信度中）：单人多平台内容矩阵从「不可能维持」变为「每周 2-3 个交付包的稳定供给」，内容获客的边际人力成本趋近于审核时间。

## 数据边界

缺失数据全部显式声明，不补数：竞品粉丝数缺失率 72.7%、播放数缺失率 69.7%（语料采集口径）；自有内容互动数据无回流（发布爬坡期）。系统设计里宁可缺失，不编造。
