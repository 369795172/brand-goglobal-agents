# 05 · 创新性、可扩展性与合规

评审维度：创新性与可扩展性（10%）+ 安全与合规性（5%）。

## 创新点

**一、声纹约束作为管道的一等公民。**

多数 AI 内容工具把「生成」当终点。我们把「像不像这个品牌说话」做成管道里的硬约束：分层声纹档案注入每个写作 Agent，独立审核 Agent 按自检清单打回。判断依据很直接：AI 时代内容供给过剩，品牌辨识度成为稀缺资产；管道越自动，声纹越关键。

**二、工程纪律用于内容生产。**

幂等同步、终态保护、单一事实源、SHA-256 证据链、发布门。这些是软件工程的日常，用在内容获客上极少见。收益是可审计：每条内容从选题到发布可回放，产能可信。

**三、自举闭环（dogfooding）。**

本参赛项目自身的海外推广，就是这条管道的第一个海外品牌案例：用 pipeline 推广 pipeline。提交截止前，X 与 Reddit 的第一批内容将由本系统产出（见路线图）。评委看到的方案与系统实际做的事，是同一件事。

## 可扩展性

**横向（品牌 × 平台）**：品牌是配置（受众分层 + 声纹 + 渠道组合 + 方向库），平台是 adapter（格式、节奏、规则、文化适配）。新增品牌边际成本趋近配置时间；新增平台边际成本是一个 adapter。

**纵向（能力栈）**：图文获客（本赛题）→ 视频获客（素材索引 + EDL 剪辑管线已就绪，复用同一状态层与发布门）→ 数据回流分析（发布包已归档，回流层接入平台数据后直接喂选题评分）。

## 安全与合规

- **原创性**：全部内容由自有管道生成，声纹约束保证表达独立性；无抄袭搬运。知识产权归参赛团队（赛事规则确认）。
- **数据合规**：研究语料全部来自平台公开数据，无私密信息、无绕过反爬；缺失数据显式声明不编造。
- **平台规则**：每个 adapter 内置平台规范检查（发布门项），内容形态贴合各平台社区文化（Reddit 反营销腔等）。
- **AI 使用披露**：内容由 AI 辅助生成、人工审核发布；关键声明挂证据锚点，三档置信度标注区分事实 / 推断 / 猜测。
- **隐私**：不采集、不存储任何用户个人数据；demo 无任何隐私输入。
